# Authority Metric Mapping

As of 2026-08-31, this is the checked-in authority map for the eight flagship GraphiQuestor metrics.

## Concerns

- `public.vw_net_liquidity` is consumed across the repo, yet its SQL definition is not present in the checked-in migrations I could inspect.
- `US_NET_LIQUIDITY_USD_BN` is registered as active, while the checked-in product consumers still read `public.vw_net_liquidity` and some digest code still references the older deactivated `BIS_GLOBAL_LIQUIDITY_USD_BN` id.
- The public methodology copy for `sovereign-stress-index` still describes a CDS and FX-vol composite, while the live screen is currently a `vw_g20_sovereign` aggregate over debt, inflation, interest burden, and a US real-rate proxy.
- `ingest-cofer` currently uses simulated quarterly rows in checked-in code. The mapping reflects the current producer path, and the source quality issue is called out in the task report.
