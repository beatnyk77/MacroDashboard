Historical Analogs & Peer Benchmarking: Feasibility & Scope

Exploring how to implement B & C without violating the core philosophy: "Observe structural reality. Do not forecast."

Approach 1

Curated Historical Episodes + Tagged Precedents

How it works: Define canonical macro episodes (e.g., 1997 Asian Financial Crisis, 2008 GFC Liquidity Drain, 2013 Taper Tantrum, 2022 Fed Aggressive Tightening). When key indicators cross specific structural thresholds, the terminal highlights the closest historical episode and overlays that episode's trajectory on current charts.

✔ Feasibility: Extremely High. Fast to query, 100% deterministic, institutional credibility, zero black-box ML risk.
Approach 2

Algorithmic Distance / Dynamic Pattern Matcher

How it works: Takes a normalized vector of current macro metrics (e.g. 10Y-2Y spread, Real Fed Funds, Global M2 YoY, Oil/Gold, FX Vol) and computes cosine similarity / Euclidean distance against every historical 30-day window since 1970 to find the top 3 mathematical nearest neighbors.

⚠ Feasibility: Moderate. Requires regular background computation or Deno Edge function batch vector indexing. Can produce false-equivalence if data series lengths vary across sources.
